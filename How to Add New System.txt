Part 1: How to Add, Edit, or Manage Tools (The Plug-and-Play Model)
To make adding tools completely plug-and-play without touching complex JavaScript, we manage tools dynamically via a central JSON configuration.

In your GitHub repository, locate /data/tools.json. To edit existing tools or add a new system (e.g., Option EGO, Astro Quant, or TARA Apex Terminal), you simply edit or append to this JSON array:
